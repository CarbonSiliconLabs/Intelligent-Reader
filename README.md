# 📖 智能阅读器 Pro (Carbon-Silicon Edition)

> **“灵感由我注入，代码由我们编写。”**
> 一个由「碳硅共生」团队（1 名人类主理人 + 大模型 AI）纯手搓的桌面沉浸式小说阅读器。

## ✨ 核心亮点
* **殿堂级 AI 拟真朗读**：接入微软 Edge 云端 AI 引擎（晓晓），使用纯内存流双线程队列播放，情感丰富，段落无缝衔接。
* **沉浸式阅读体验**：双击进入全屏模式，内置“羊皮纸、豆沙绿、纯白、夜间”四款护眼主题。
* **全功能书架系统**：支持多本书籍导入，像素级断点记忆，以及书签标记功能。
* **全键盘操作**：支持快捷键（空格翻页、左右切章、Esc 退出沉浸）。
